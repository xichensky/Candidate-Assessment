# 工作风格测评系统

一个基于 Next.js + React + Tailwind CSS 开发的候选人工作风格测评网站，用于评估候选人在压力、分歧与协作中的自然反应模式。

## 📋 功能特性

- **欢迎页面**：清晰的测评说明和评估维度介绍
- **智能测评引擎**：
  - 10道精心设计的情境判断题
  - 实时进度条显示
  - 答题验证机制
  - 流畅的页面切换动画
- **科学评分系统**：
  - 内在能量 & 弹性指数（0-12分）
  - 防御性 & 攻击风险指数（0-12分）
  - 团队协作倾向（-3至+3分）
- **可视化结果报告**：
  - 雷达图展示工作风格
  - 详细的分数条图表
  - 个性化的优势与建议分析
- **HR 后台管理**：
  - 查看所有候选人测评结果
  - 📄 **导出功能**：支持导出为 Word / PDF 格式（v0.2.0 新增）
  - 🗑️ **删除功能**：单条记录精准删除（v0.2.0 新增）
  - 搜索和排序功能
  - 统计数据展示
- **优秀的用户体验**：
  - 响应式设计，支持移动端
  - 深色模式支持
  - 流畅的动画效果
  - 清晰的视觉反馈

## 🛠️ 技术栈

- **框架**：Next.js 14 (App Router)
- **UI 库**：React 18
- **样式**：Tailwind CSS
- **动画**：Framer Motion
- **图表**：Recharts
- **导出**：docx, jspdf, jspdf-autotable (v0.2.0 新增)
- **语言**：TypeScript

## 📊 评分逻辑说明

### 模块1：内在能量 & 弹性指数（0-12分）
- **高分（10-12）**：出色的内在驱动力和问题解决韧性
- **中等（7-9）**：较好的能量与弹性
- **正常（4-6）**：能量弹性适中
- **偏低（0-3）**：需要关注能量补充

### 模块2：防御性 & 攻击风险指数（0-12分）
- **偏高（9-12）**：建议关注开放性
- **中等（6-8）**：有一定防御倾向
- **正常（3-5）**：防御性适中
- **良好（0-2）**：开放接纳

### 模块3：团队协作倾向（-3至+3分）
- **优秀（3）**：强协作导向
- **良好（1-2）**：倾向团队协作
- **正常（-1至0）**：协作与独立平衡
- **偏个人（-3至-2）**：倾向独立工作

## 🎨 自定义配置

### 修改题目

编辑 `data/questions.ts` 文件，按照现有格式添加或修改题目。每个选项的 `scores` 对象包含三个维度的得分。

### 调整评分标准

修改 `utils/scoring.ts` 中的评分函数，自定义评级描述和综合评价逻辑。

### 自定义样式

- 修改 `tailwind.config.ts` 调整主题颜色
- 编辑 `app/globals.css` 自定义全局样式

## 📝 使用说明

### 候选人端
1. 测评者点击"开始测评"进入问卷
2. 按第一直觉选择最符合的选项
3. 系统自动进行进度追踪和答题验证
4. 完成所有题目后自动计算并展示结果
5. 可以查看雷达图、详细分数和个性化建议
6. 支持重新测评功能

### HR 后台（/hr-admin）
1. 查看所有候选人测评结果列表
2. 点击记录查看详细评分和答题详情
3. 使用导出功能：
   - 点击「导出」按钮
   - 选择「导出为 Word」或「导出为 PDF」
   - 文件自动下载到本地
4. 删除测评记录：
   - 点击「删除」按钮
   - 确认后从列表中移除
