12. [ ] 使用 Word 打开文件，检查内容：
    - [ ] 标题：工作风格测评结果
    - [ ] 候选人信息（姓名、职位、日期）完整
    - [ ] 三个维度得分正确
    - [ ] 等级描述正确
    - [ ] 报告生成时间显示
    - [ ] 免责声明显示

#### PDF 导出测试

14. [ ] 点击「导出」→「导出为 PDF」
15. [ ] 按钮显示 loading 状态

18. [ ] 使用 PDF 阅读器打开文件，检查内容：
    - [ ] 标题：工作风格测评结果
    - [ ] 候选人信息完整
    - [ ] 三个维度得分表格正确

#### 下拉菜单交互测试

6. [ ] 对话框显示内容：

8. [ ] 点击「取消」按钮

#### 批量删除测试（压力测试）
