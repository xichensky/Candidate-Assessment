## 📧 邮件通知测试流程

### 1. 配置邮件服务
- [ ] 复制 `.env.example` 为 `.env.local`
- [ ] 填写 SMTP 配置信息
  ```env
  SMTP_HOST=smtp.gmail.com
  SMTP_PORT=587
  SMTP_SECURE=false
  SMTP_USER=your-email@gmail.com
  SMTP_PASSWORD=your-app-password
  SMTP_FROM=your-email@gmail.com
  NEXT_PUBLIC_BASE_URL=http://localhost:3000
  ```
- [ ] 重启开发服务器（Ctrl+C 然后 npm run dev）

### 2. 测试邮件发送
- [ ] 完成一次完整的候选人测评

## 📊 数据验证

### 检查 localStorage
1. 打开浏览器开发者工具（F12）
2. 切换到 Application 标签
3. 展开 Local Storage
4. 点击 http://localhost:3000
5. 查找 `assessment_submissions` 键
6. 验证数据结构：
```json
[
  {
    "id": "...",
    "candidateInfo": {
      "name": "...",
      "position": "..."
    },
    "answers": [...],
    "result": {...},
    "submittedAt": "..."
  }
]
```
